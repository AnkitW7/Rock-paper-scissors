# Rock-paper-scissors

A simple command-line Rock Paper Scissors game written in Python.

## Features

- Play Rock, Paper, or Scissors against the computer
- Random computer choices
- Running win counters for the player and computer
- Quit the game at any time

## Requirements

- Python 3

## How to Run

From the project folder, run:

```bash
python rock_paper_scissors.py
```

Enter `rock`, `paper`, or `scissors` when prompted. Enter `q` to quit.

## Example

```text
Type Rock/Paper/Scissors or Q to quit: rock
computer picked scissors.
you won !
Type Rock/Paper/Scissors or Q to quit: q
You won 1 times
The computer won 0 times
-------------BYE------------
```
